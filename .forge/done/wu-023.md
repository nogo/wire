# WU-023: Config Module Updates

## Type
AFK

## User Stories Covered
15

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Add `drain_timeout` (default 30s) and `queue_depth` (default 200) to config. Validate warmup models against VRAM capacity, log warning (not error) if exceeded.

## Acceptance criteria
- [ ] `drain_timeout` config field added (default 30s)
- [ ] `queue_depth` config field added (default 200)
- [ ] Warmup models validated against VRAM capacity at startup
- [ ] Warning logged (no error) if warmup exceeds VRAM capacity, system still starts

## Blocked by
None - can start immediately
