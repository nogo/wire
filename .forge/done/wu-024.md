# WU-024: Hub Integration with VRAM Tracker

## Type
AFK

## User Stories Covered
14

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Move Hub's GPU polling to VRAM tracker. Hub receives GPU state via `PushGPUState()` and broadcasts `MsgGPUTick` from VRAM tracker instead of polling directly.

## Acceptance criteria
- [ ] Hub's GPU polling code moved to VRAM tracker
- [ ] Hub subscribes to VRAM tracker for GPU state via `PushGPUState()`
- [ ] `MsgGPUTick` broadcast to subscribers sourced from VRAM tracker
- [ ] Hub's other polling (backend /metrics, /slots, /props, remote stats, model discovery) unchanged
- [ ] Monitor dashboard continues showing GPU metrics (VRAM, temperature, power)

- WU-019 (VRAM Tracker Core Module)
