# WU-026: Warmup Model Admission

## Type
AFK

## User Stories Covered
4, 15

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Submit warmup models through gateway admission path (no special privileges). Bounded retry (3 attempts/5min) if VRAM insufficient. Process in config order.

## Acceptance criteria
- [ ] Warmup models submitted through gateway admission path (same as regular requests)
- [ ] No special privileges for warmup models; same admission checks apply
- [ ] Bounded retry: 3 attempts over 5 minutes if VRAM insufficient
- [ ] Warmup models processed in config order
- [ ] Warning logged if warmup models can't fit, system still starts
