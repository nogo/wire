# WU-019: VRAM Tracker Core Module

## Type
AFK

## User Stories Covered
2, 11, 12, 18, 19

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Implement `internal/vram/` deep module encapsulating GPU discovery, backend abstraction, VRAM budget tracking, and admission decisions. Includes AMD sysfs and noop (CPU-only) backends, GGUF file size ×1.3 estimation, HuggingFace cache scan at startup, and sysfs reconciliation.

## Acceptance criteria
- [ ] GPU backend auto-detection chain (AMD sysfs → noop) implemented (NVIDIA NVML deferred per Out of Scope)
- [ ] Interface methods `Discover()`, `CanFit(estimate uint64) bool`, `Reserve(model, estimate)`, `Release(model)`, `PushGPUState()` working
- [ ] `CanFit` uses budget: `total - (actual_sysfs_used + pending_releases)`
- [ ] VRAM estimation: GGUF file size ×1.3 heuristic via `os.Stat` per model
- [ ] HuggingFace cache scan at init populates VRAM estimates for cached models
- [ ] Sysfs reconciliation updates reservations based on actual GPU readings per poll tick
- [ ] CPU-only noop backend returns `CanFit=true` always
- [ ] Unit tests mock backends and verify admission, eviction logic, and reconciliation

## Blocked by
None - can start immediately
