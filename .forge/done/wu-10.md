# Rewrite config and strip external backends

## Outcome
Wire's config uses glob-pattern model definitions, a warmup list, and a max_models limit. External backend support (Anthropic translation, OpenAI/Ollama proxy) is removed. The CLI has only `start`, `build`, `remove`, and `version` commands. All warmup models start at boot via the existing process manager. Requests for non-warmup models return 404 (on-demand loading is wu-11). Default listen port is 9480.

## Values
1. Simplicity — delete everything not needed for llama-server management.
2. Correctness — the build is green, all tests pass, warmup models work end-to-end.
3. No future-proofing — no compatibility shims, no dead interfaces, no preserved abstractions.

## Requirements

### 1. New Config struct
Replace the current Config and Backend with:

```go
type Config struct {
    Listen    string                  `yaml:"listen"`
    Monitor   bool                    `yaml:"monitor"`
    MaxModels int                     `yaml:"max_models"`
    Models    map[string]ModelParams  `yaml:"models"`
    Warmup    []string                `yaml:"warmup"`
}

type ModelParams struct {
    Context   int      `yaml:"context"`
    GPULayers int      `yaml:"gpu_layers"`
    Slots     int      `yaml:"slots"`
    Pooling   string   `yaml:"pooling"`
    Extra     []string `yaml:"extra"`
}
```

The `models` map keys are glob patterns (e.g. `"unsloth/Qwen3*-A3B-*"`). Delete `Backend`, `IsManaged()`, `IsExternal()`, `ValidationError`, `WriteFile()`.

### 2. Glob matching
Add a `MatchModel(name string) (ModelParams, bool)` method on Config. Linear scan over `Models` keys using `filepath.Match(pattern, name)`. First match wins. Return zero ModelParams and false if no match.

### 3. Defaults and validation
`applyDefaults()`:
- `Listen` defaults to `":9480"`
- `MaxModels` defaults to `1` when 0
- `Slots` defaults to `1` when 0 for each ModelParams

`validate()`:
- Each warmup entry must match exactly one pattern in Models. Error if zero or multiple matches.
- `len(Warmup) <= MaxModels`. Error if exceeded.

Remove all old validation (model-xor-url check, external backend validation).

### 4. Rewrite process manager
`Manager` changes:
- `Start()` iterates `cfg.Warmup` (not cfg.Backends), resolves each via `cfg.MatchModel()`, starts a supervisor goroutine per warmup model.
- `procState` stores `modelName string` and `params ModelParams` instead of `backend config.Backend`.
- `Addr(name string)` and `Healthy(name string)` are keyed by model name (the full HF ref), not backend name.
- Delete the external backend branches in `Healthy()` and `Addr()`.
- Delete `Swap()` and the swap channel/request types.
- `buildArgs()` takes `modelName string, params ModelParams, port int` — passes `-hf modelName` and constructs flags from ModelParams.
- The `procs` map is keyed by model name string.

### 5. Rewrite gateway
- Delete `handleAnthropicProxy()`.
- Delete `buildReplacer()` and `replacingReader`.
- `handleRoute()`: extract model from JSON body, call `g.cfg.MatchModel(model)` to validate the model is known, then look up in manager by model name. If not loaded, return 503 with "model not loaded" (on-demand loading is wu-11).
- `handleModels()`: list models from the manager's running processes. No fan-out to backends. Each entry has `id` = model name, `object` = "model", `owned_by` = "wire".
- Delete the `routeTable` type and `route.go` entirely.
- Affinity table: `newAffinityTable` takes the warmup model list + resolved ModelParams (needs slots count). Keyed by model name instead of backend name.

### 6. Strip CLI
Remove `swap`, `stop`, `status` commands and their functions (`runSwap`, `runStop`, `runStatus`). Remove `listenURL()`. Delete `internal/pidfile/` package.

Update usage text:
```
Usage: wire <command> [arguments]

Commands:
  start               Start the gateway (foreground)
  build               Build and install llama-server from source (ROCm)
  remove              Remove a previous llama-server installation
  version             Print version and exit
```

Remove SIGHUP handler from `runStart()`. Remove `swapMu` and the swap goroutine. Keep SIGTERM/SIGINT for graceful shutdown.

### 7. Update tests
- Config tests: rewrite all tests for the new shape. Test glob matching, warmup validation, max_models validation, defaults.
- Gateway tests: remove any Anthropic proxy tests. Test model routing via glob match. Test /v1/models response shape.
- Manager tests: rewrite for model-name keying. Remove swap tests.
- CLI tests: remove `TestDispatchSwapMissingArgs`. Update dispatch tests for reduced command set.
- Affinity tests: update to use model names instead of backend names.
- Delete all translate/anthropic tests.

## Constraints
- `mise run check` must pass.
- Delete `internal/translate/` directory entirely.
- Delete `internal/pidfile/` directory entirely.
- Delete `internal/gateway/route.go`.
- Do not preserve dead code, unused interfaces, or compatibility shims.
- Do not add on-demand model loading — that is wu-11. Non-warmup models return 503.
- The `backendManager` interface in gateway.go should be updated to reflect the new manager API, not preserved for hypothetical future use.

## Failure Modes
- **Glob pattern never matches**: user typos a warmup entry that doesn't match any pattern. Detection: startup validation rejects it. The validate() function must test every warmup entry.
- **Multiple patterns match same model**: ambiguous config. Detection: first-match-wins is documented but could surprise users. Log which pattern matched at startup for warmup models.
- **Affinity table not initialized for on-demand models**: wu-11 will add models dynamically. For now, affinity only covers warmup models. Non-warmup requests get 503 before reaching affinity. No risk.
- **Tests reference deleted types**: compiler catches this. No runtime risk.
