# Add build script and systemd service

## Outcome
`wire build` compiles and installs llama-server from source with ROCm support. A systemd user service runs `wire start` on boot. `systemctl --user start wire` / `stop` / `status` works.

## Values
1. Reproducible builds — `wire build` always builds from the latest llama.cpp tag with the correct flags.
2. Standard systemd integration — journal logging, auto-restart, proper dependency ordering.
3. Portable — ROCm GPU target is configurable, not hardcoded.

## Context
- The existing build script at `/home/nogo/Development/projects/knotenpunkt/beta/bin/inference.sh` contains a working `cmd_build` and `cmd_remove` function for ROCm builds. The key cmake flags are:
  - `-DGGML_HIP=ON -DAMDGPU_TARGETS="gfx1151" -DGGML_HIP_ROCWMMA_FATTN=ON -DGGML_NATIVE=ON`
  - Install prefix: `$HOME/.local`
  - Source dir: a local llama.cpp git checkout.
- `internal/cli/cli.go` — CLI dispatch. Add `build` and `remove` subcommands.
- `cmd/wire/main.go` — entry point.
- This project uses Go 1.26.

## Creates
- `internal/build/build.go` — build and remove logic for llama-server from source.
- `deploy/wire.service` — systemd user service unit file.

## Modifies
- `internal/cli/cli.go` — add `build` and `remove` subcommands.
- `Makefile` — add `install` target that copies the binary and service file.

## Requirements

### 1. Build command (`wire build`)
Accepts optional flags:
- `--source <path>` — path to llama.cpp git checkout. Default: `~/Development/llama.cpp`. Environment variable: `WIRE_LLAMA_SRC`.
- `--gpu-target <target>` — AMD GPU target. Default: `gfx1151`. Environment variable: `WIRE_GPU_TARGET`.
- `--prefix <path>` — install prefix. Default: `~/.local`. Environment variable: `WIRE_PREFIX`.

Steps:
1. `cd` to the source directory.
2. `git fetch --tags`, find latest tag.
3. Compare with current checkout. If different, `git checkout <latest>`.
4. Remove previous installation (if install manifest exists).
5. Run cmake configure:
   ```
   cmake -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=<prefix> \
     -DGGML_HIP=ON -DAMDGPU_TARGETS=<gpu-target> -DGGML_HIP_ROCWMMA_FATTN=ON -DGGML_NATIVE=ON
   ```
6. Run `cmake --build build --config Release -j <nproc>`.
7. Run `cmake --install build`.
8. Print installed version and path.

All steps log progress via `slog`. Build output streams to stdout.

### 2. Remove command (`wire remove`)
Read `<source>/build/install_manifest.txt`. Delete each listed file. Print count.

### 3. Systemd user service (`deploy/wire.service`)
```ini
[Unit]
Description=Wire inference gateway
After=network.target

[Service]
Type=simple
ExecStart=%h/.local/bin/wire start
Restart=on-failure
RestartSec=5
Environment=WIRE_CONFIG=%h/.config/wire/config.yaml

[Install]
WantedBy=default.target
```

### 4. Makefile install target
```makefile
install: build
	install -Dm755 wire $(HOME)/.local/bin/wire
	install -Dm644 deploy/wire.service $(HOME)/.config/systemd/user/wire.service
	systemctl --user daemon-reload
```

Also add an `uninstall` target:
```makefile
uninstall:
	systemctl --user stop wire || true
	systemctl --user disable wire || true
	rm -f $(HOME)/.local/bin/wire
	rm -f $(HOME)/.config/systemd/user/wire.service
	systemctl --user daemon-reload
```

### 5. Build logic implementation
Implement in `internal/build/build.go` using `os/exec` to run git, cmake commands. Each command's stdout/stderr should be connected to `os.Stdout`/`os.Stderr` directly (user wants to see build progress). Return errors with context (`fmt.Errorf("cmake configure: %w", err)`).

### 6. CLI integration
Add to the subcommand dispatch:
- `wire build [--source PATH] [--gpu-target TARGET] [--prefix PATH]`
- `wire remove [--source PATH]`

Parse flags with `flag.NewFlagSet` for each subcommand.

## Constraints
- `go build ./...` must pass.
- `go test ./...` must pass (build tests can be skipped with a build tag if they require llama.cpp source).
- Do not modify files outside the Modifies/Creates list unless strictly required.
- The build command must not hardcode the GPU target. Different AMD GPUs need different targets.
- The systemd service must be a user service (not system), installed to `~/.config/systemd/user/`.

## Failure Modes
- **Wrong GPU target**: build succeeds but llama-server crashes or runs on CPU. Detection: `wire status` shows healthy but inference is slow. Mitigation: document how to find the correct target (`rocminfo | grep gfx`).
- **cmake not installed**: `wire build` fails with unhelpful error. Detection: check for cmake before starting. Print "cmake is required: sudo pacman -S cmake".
- **Stale install manifest**: previous build's manifest points to files that were manually deleted. Detection: `wire remove` prints "removed 0 files". This is fine — not harmful.
- **systemd user service not started on boot**: user must run `loginctl enable-linger <user>` for user services to start without a login session. Document this in output of `make install`.
