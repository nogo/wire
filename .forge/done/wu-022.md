# WU-022: Process Manager Ticket API + Eviction Logic

## Type
AFK

## User Stories Covered
1, 5, 6, 16

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Modify `internal/process/` `LoadOrGet` to return async `LoadTicket`. Implement cascading LRU eviction (minimum models to free required VRAM) with graceful in-flight request draining.

## Acceptance criteria
- [ ] `LoadOrGet` returns `LoadTicket` asynchronously
- [ ] Cascading LRU eviction finds minimum idle models to free enough VRAM for incoming model
- [ ] Drain timeout configurable (default 30s), new requests to draining model rejected immediately
- [ ] In-flight requests get 30s grace period before SIGTERM + 10s WaitDelay
- [ ] Eviction minimizes number of models evicted
- [ ] Unit tests verify ticket API, eviction logic, and drain behavior
