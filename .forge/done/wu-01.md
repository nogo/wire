# Scaffold project and load config

## Outcome
`go build ./...` passes. A `wire` binary exists that reads `~/.config/wire/config.yaml` and prints the parsed config to stdout. Running `wire` with no config file prints a helpful error with the expected path.

## Values
1. Minimal dependencies — standard library plus a YAML parser, nothing else.
2. Correct Go 1.26 idioms — `new(expr)`, `errors.AsType[T]`, `for range n`, structured logging with `log/slog`.
3. Config is the single source of truth for system state.

## Context
- This is a greenfield Go project at `/home/nogo/Development/projects/inference`.
- `Makefile` exists: `make build` runs `go build -o wire ./cmd/wire`.
- `.gitignore` exists.

## Requirements

### 1. Go module
Initialize `github.com/nogo/wire` with `go 1.26.0`. Only external dependency: `gopkg.in/yaml.v3`.

### 2. Config types
```go
type Config struct {
    Listen   string              `yaml:"listen"`
    Backends map[string]Backend  `yaml:"backends"`
    Peers    []string            `yaml:"peers"`
}

type Backend struct {
    // Managed backend (llama-server)
    Model     string   `yaml:"model"`      // HuggingFace ref, e.g. "Qwen/Qwen3-Coder-30B-A3B-Instruct-GGUF:Q4_K_M"
    Context   int      `yaml:"context"`    // Context window size
    GPULayers int      `yaml:"gpu_layers"` // -ngl flag
    Pooling   string   `yaml:"pooling"`    // "mean", "cls", "rank" — triggers --embedding flag
    Extra     []string `yaml:"extra"`      // Additional llama-server flags

    // External backend (Ollama, OpenAI, Anthropic, etc.)
    URL      string `yaml:"url"`       // If set, backend is external — no process management
    APIKey   string `yaml:"api_key"`   // Bearer token or x-api-key
    Provider string `yaml:"provider"`  // "openai" (default) or "anthropic"
}
```

### 3. Config loading
Function `Load() (*Config, error)` that:
- Reads from `~/.config/wire/config.yaml` (respect `XDG_CONFIG_HOME` if set).
- Returns a clear error if the file doesn't exist, including the expected path.
- Environment variable `WIRE_CONFIG` overrides the file path.
- Validates: `Listen` defaults to `:8080` if empty. Each backend must have either `Model` or `URL` set (not both, not neither). `Provider` defaults to `"openai"`.

### 4. Backend classification
Method `Backend.IsManaged() bool` returns true when `URL` is empty (wire manages the llama-server process). Method `Backend.IsExternal() bool` is the inverse.

### 5. Entry point
`cmd/wire/main.go` calls `config.Load()`, logs the loaded config with `slog.Info`, and exits. Use `slog` for all logging. No `fmt.Println` for operational output.

### 6. Tests
Test config loading with:
- Valid config with mixed managed and external backends.
- Missing file produces error mentioning the path.
- Backend with both `Model` and `URL` set fails validation.
- Backend with neither `Model` nor `URL` set fails validation.
- Default values applied correctly.

## Constraints
- `go build ./...` must pass.
- `go test ./...` must pass.
- Do not create files outside the Creates list unless strictly required.
- Use `errors.AsType[T]` for typed error inspection in tests if applicable.
- Use `new(expr)` where pointer-to-value is needed.

## Failure Modes
- **Config path wrong on XDG systems**: user has `XDG_CONFIG_HOME` set but config loads from `~/.config` anyway. Detection: test with `XDG_CONFIG_HOME` set to a temp dir.
- **YAML parsing silently ignores unknown fields**: user typos a field name and it's silently dropped. Detection: consider `yaml.KnownFields(true)` or document that unknown fields are ignored.
- **Backend validation missing**: a backend with no `Model` and no `URL` passes validation, gateway crashes later. Detection: unit test covers this case.
