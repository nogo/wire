# WU-020: Request Queue Module

## Type
AFK

## User Stories Covered
8, 9, 10, 17

## Parent
.forge/prd/vram-aware-scheduling.md

## What to build
Implement `internal/gateway/queue/` deep module with per-model priority queue, time-bounded waits, and coalesced loading. Exposes ticket-based async API for request enqueueing.

## Acceptance criteria
- [ ] `Enqueue(model, priority, ctx) -> Ticket` interface returns ticket immediately
- [ ] Ticket type with `Ready() <-chan string`, `Release()`, `Err() error` methods
- [ ] Priority tiers: chat (high, 30s), completions (medium, 15s), embeddings/rerank (low, 5s)
- [ ] Global queue depth cap: 200 requests total across all models
- [ ] Coalesced loading: concurrent requests for same unloaded model share one `LoadTicket`
- [ ] Model eviction cancels all queued requests for that model with 503 Retry-After
- [ ] Unit tests verify priority ordering, time budgets, coalescing, cancellation, depth cap

## Blocked by
None - can start immediately
